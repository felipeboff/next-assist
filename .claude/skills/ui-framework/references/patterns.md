# Screen patterns

Recipes for whole screens, composed only from framework components. A composition earns a recipe
here once it appears on two or more screens.

No recipes yet. Expected candidates, from the PRD screens:

- Login (Screen 1)
- Employee chat: message list, composer, quick-reply options, agent action chips above each
  reply with their expandable detail (Screens 2 and 3)
- Analyst console: conversation list with filters and status, conversation history, employee's
  tickets side panel, take over / hand back / close actions (Screens 4 and 5)

Each recipe: when to use it, the composition (a short TSX example), and its loading, empty and
error states.
